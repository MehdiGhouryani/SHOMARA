# پردازش دارایی‌های شخصیت (WebP ۸۰۰ با آلفا)

## وضعیت فایل‌ها

- **Dana و Fandogh:** از بستهٔ اصلی بدون تغییر (۳۶ فایل، آلفای واقعی، ۸۰۰×۸۰۰).
- **Main، Number، Roka:** پس‌زمینهٔ رنگی بسته پخته بود، پس با حذف خودکار پس‌زمینه از نسخهٔ 1024 (PNG) ساخته شدند (۵۴ فایل، ۸۰۰×۸۰۰، آلفا). حجم همه زیر ۷۰ کیلوبایت.

## محدودیت‌های حذف خودکار

- سایهٔ کم‌رنگ زیر پا باقی مانده (روی پس‌زمینهٔ تیره دیده می‌شود).
- در Roka یک تکهٔ کم‌رنگ کنار دم و سایهٔ صورتی زیر پا باقی مانده.
- با این حال برای روی روشن و تیره قابل استفاده است.

## توصیه

از طراح بخواهیم برای این سه شخصیت خروجی شفاف واقعی (بدون سایهٔ پخته) بگیرد. این فقط فرمت را تصحیح می‌کند و طراحی تغییر نمی‌کند. تا آن موقع همین فایل‌ها استفاده شوند.
