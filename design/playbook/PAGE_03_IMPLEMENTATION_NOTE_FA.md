# یادداشت اجرای صفحهٔ ۰۳ — Phone/OTP (خانوادهٔ 03)

شاخه: `page-03-phone` (زنجیره‌شده از `page-02-profile`/`45509a2`). تاریخ: ۲۰۲۶-۱۱-۰۷.

## چه چیزی بهبود یافت

1. **ساختار صفحهٔ تلفن** (`WelcomePhone.kt`): hero فشردهٔ «ماسکوت پشت تپه» (همان زبان بصری ۰۱/۰۲، بازاستفادهٔ اشکال و ماسکوتِ ثبت‌شده — بدون asset تازه) + بدنهٔ حذف‌شده‌بازگشته (`WelcomeBody` — ناخوانگویی F-27 رفع شد) + CTA پین‌شدهٔ پایین (الگوی Profile) + حذف فضای مردهٔ ~۹۰۰px.
2. **OTP** (`OnboardingHost.kt`): «تأیید کد» مستقیم زیر کیپد (قبلاً زیر فولد می‌افتاد)؛ دکمه‌های DEBUG و ارسال/چسباندن جفتی‌شدند تا کیپد کامل بالای فولد بماند؛ فاصله‌گذاری گروه عنوان/سلول‌ها فشرده.
3. **a11y** (`ShomaraOtp.kt` + ‏`OnboardingA11y.kt`): سلول‌های OTP خطا را خودشان اعلام می‌کنند (stateDescription + error برای Invalid/Expired)؛ قرارداد traversal با رندر واقعی هم‌گام شد + دو تست جدید. رشتهٔ تازهٔ واحد: «کد تأیید درست نیست.» (برچسب کنار expiredLabel — وضعیت Invalid قبلاً هیچ برچسبی نداشت).
4. **رنگ CTA غیرفعال**: روی این صفحه نگاشت اشتراکی (روشنِ واضح) — تیرهٔ مالک‌محور ویژهٔ Profile ماند؛ علت: CTA تیرهٔ غیرفعال روی دستگاه «روشن به‌نظر می‌رسد ولی کار نمی‌کند» را بازتولید کرد. [سوال باز مالک: اگر تیره در همهٔ صفحات خواسته می‌شود، یک تصمیم کافی است.]
5. **verifier**: `verify-demo-auth-isolation` با تصمیم مالک (حذف بنر حالت توسعه) هم‌تراز شد — حالا «نبودِ بنر» را assert می‌کند (۲۰۲۶-۱۱-۰۶).

## شواهد

- قبل/بعد در `build-reports/android/device-check/p03-*` (۴۱۲/۳۹۰/۳۶۰/۲۰۰٪ + جریان کامل تا Profile).
- گیت‌ها روی کامیت نهایی: static ‏90/90، android:gate ‏PASS.
- راستی‌آزمایی مستقل qa-gatekeeper: ‏PASS 7/7 (scope، بهداشت diff، static، تست‌های ‏۹۲+۷۴ با ‏--rerun-tasks، verifier، انزوای صفحهٔ قفل ۰۲، یگانگی رشتهٔ تازه).

## سوال‌های باز مالک

- رنگ CTA غیرفعال در سایر صفحات (بند ۴).
- جهت فلش «ادامه» (→ مثل نمونه — بدون تغییر).
- TalkBack شنیداری روی این دو صفحه: ساختاری تایید شده؛ اعلام شنیداری روی این بوتِ شبیه‌ساز TTS-init fail داشت (الگوی شناخته‌شده) — دستگاه واقعی نیازمند پوشش.
