# یادداشت اجرای صفحهٔ ۰۵ — Grade/Placement (خانوادهٔ 05)

شاخه: `page-05-placement` (زنجیره از `page-03-phone`). تاریخ: ۲۰۲۶-۱۱-۰۷.

## واقعیتِ کشف‌شده (DISCOVER)

Placement فعلاً **stub** است: مسیر تصمیم سرور (`withServerDecision`) هیچ caller تولیدی ندارد — هیچ endpoint/gateway سرور وجود ندارد. تنها state قابل‌رسیدن در تولید، pending («در حال آماده‌سازی نقطهٔ شروع…») است؛ skip فقط DEBUG است؛ در release این گام **بن‌بست** است (نه skip، نه تصمیم).

## چه چیزی اصلاح شد (محدود به scope بهبود، بدون تصمیم سرور)

1. **باگ پایهٔ انتخابی** (`ProfileScreens.kt` + ‏`OnboardingHost.kt`): حالت skip همیشه هاردکد «پایه اول ابتدایی» می‌نوشت — کودکی که پایهٔ سوم انتخاب کرده بود G1 می‌خواند. حالا `chosenGradeLabel` از draft می‌آید (`ShomaraProfileDraft.gradeLabel`). توجه صادقانه: این رندر در جریان فعلی هرگز نمایش داده نمی‌شود (skip بلافاصله به shell می‌رود) — اصلاح قراردادی است و با تست پوشش دارد.
2. **a11y**: متن وضعیت کارت `liveRegion = Polite` گرفت — وقتی در آینده تصمیم سرور برسد، TalkBack تغییر را اعلام می‌کند (گاپ ثبت‌شده در DISCOVER).

## ثبت برای مالک (BLOCKED_OWNER_DECISION)

- **بن‌بست release در این گام**: تا وقتی منبع تصمیم سرور وصل نشود (یا ADR-0039 مسیر آفلاین را بازطراحی کند)، کاربر release در این صفحه بدون خروجی می‌ماند. پیشنهاد: یا skip موقت production، یا اتصال به منبع — تصمیم با مالک.
- Blueprint خانوادهٔ ۰۵ (کارت‌های پایه با قفل/ارزیابی تعیین‌سطح) فراتر از stub فعلی ساخته نشده — «feature:placement» ماژول وجود ندارد.
