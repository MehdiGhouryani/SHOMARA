# STATION BUILD PHASES — فازبندی ساخت تجربهٔ ایستگاه

**وضعیت:** canonical plan — ترتیب اجرای دقیقِ زیرساخت UX ایستگاه‌ها طبق
`STATION_EXPERIENCE_BLUEPRINT.md`. هر فاز: ورودی/خروجی، فایل‌های هدف، معیار پذیرش ماشینی،
وابستگی. وضعیت اجرا فقط در `NATIVE_IMPLEMENTATION_BACKLOG.csv` (ردیف‌های جدید UX-0xx).

**اصل حاکم:** محتوای ایستگاه‌ها (ST09–ST25) موازی ادامه دارد و **تولید گرافیک نهایی
فقط بعد از قطعی‌شدن کل محتوا** (تصمیم مالک) — تا آن موقع همهٔ الگوها با placeholder
تختِ token-دار ساخته می‌شوند و گرافیک بدون تغییر قرارداد جایگزین می‌شود.
