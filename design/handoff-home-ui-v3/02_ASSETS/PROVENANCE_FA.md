# منشأ و اصالت دارایی‌ها

## دارایی‌های سفارشی این بسته

- SVGهای navigation، node state، lesson topic و UI icon برای این handoff به شکل برداری و اختصاصی ساخته شده‌اند.
- معادل Android VectorDrawableها از همان ساختار ظاهری تولید شده‌اند تا در runtime به SVG renderer وابسته نباشند.
- `garden_path_footer.webp` یک تصویر تزئینی جدید و AI-generated برای لبهٔ پایین صفحه است؛ شخصیت، متن، لوگو یا محتوای آموزشی واقعی در آن وجود ندارد.
- پیش‌نمایش‌های صفحه و component sheet، mockup برنامه‌نویسی‌شده هستند و screenshot اپ یا evidence دستگاه واقعی نیستند.

## دارایی‌های شخصیت

Main، Number و Fandogh متعلق به مجموعهٔ رسمی SHOMARA هستند و از مسیرهای checkout پروژه مصرف می‌شوند. این ZIP آن‌ها را duplicate نمی‌کند تا version و provenance اصلی از بین نرود. مسیرهای دقیق در `03_ANDROID/kotlin/CHARACTER_ASSET_INTEGRATION_FA.md` ثبت شده‌اند.

## مسئولیت Harness

پیش از ادغام در محصول، مالکیت/مجوز هر تصویر موجود در مخزن را مطابق policy خود پروژه بررسی کنید. دارایی تزئینی این بسته را با character source رسمی اشتباه نگیرید و آن را mascot محصول معرفی نکنید.
