# موکاپ‌های بازسازی UI — دست مرورگر مالک

## روش مرور

هر فایل HTML را در مرورگر باز کنید. هر «حالت» یک فریم ۳۶۰dp است که کنار هم چیده شده‌اند.
هیچ سروری لازم نیست — CSS محلی است.

## فایل‌ها

| فایل | صفحات | پنل‌ها |
|---|---|---|
| `01-path.html` | تب «مسیر» | ready, loading, offline, error+retry, empty, locked, correct, back/resume |
| `02-practice.html` | تب «تمرین» | ready, loading, empty, offline, error+retry, resume |
| `03-me.html` | تب «من» | ready, loading, empty, offline, error+retry, منو |
| `04-settings-menu.html` | تنظیمات + منوها | ready, dirty/saving/saved, toggle-fail, منوی هدر, شیت علت قفل |
| `05-logo-splash.html` | لوگو/اسپلش | resolving, reduce-motion, recovery, ماتریس اندازه |
| `06-levels.html` | مراحل (ایستگاه) | شروع, درس, پاسخ صحیح, پاسخ غلط, نتیجه |

توکن‌ها همه از `HOME_VISUAL_TOKENS.json` (v1.1.0) خودتان آمده‌اند — هیچ عددی از جایی دیگر نیست.

## قواعد رعایت‌شده (و باید در مرور چشم بماند)

- تک-CTA اصلی در هر viewport تصمیم (AGENTS §6)
- هدف لمسی ≥48dp؛ دکمهٔ اصلی ≥56dp
- بدون سکه/جان/streak/تروفی/loot/leaderboard (§3.8)
- پاسخ غلط بدون سرزنش (§3.9)
- قفل با دلیل کامل، نه فقط آیکون
- offline = عادی، نه خطا
- RTL و فارسی تمام‌قد

## آنچه نیاز به چشم شما دارد (من تصویر نمی‌بینم)

1. **آیا زبان v3 (بنفش/سفید/lavender) را تأیید می‌کنید به‌عنوان زبان بصری همهٔ صفحات کودک؟**
2. **لوگو**: نماد «ش» موقت است. اگر طرح نهایی دارید، بفرستید تا جایگزین شود.
3. **عنوان‌ها/متن‌ها**: همهٔ رشته‌ها موکاپ‌اند؛ نسخهٔ قطعی در منبع string canonical ثبت می‌شود.

## صادقانه

- من نمی‌توانم رندر را ببینم؛ این موکاپ‌ها از روی spec شما و tokens ساخته شده‌اند، نه از بازرسی بصری.
- برخی حالت‌ها (مانند متن خطای offline) پیشنهادی‌اند و قبل از پیاده‌سازی باید با شما قطعی شوند.
- این موکاپ‌ها جایگزین صفحات v1 تأییدشده نیستند؛ فقط زبان v3 را به صفحات دیگر گسترش می‌دهند.
